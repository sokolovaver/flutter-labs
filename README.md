# TaskTrack

## Описание проекта

TaskTrack — простое и удобное мобильное приложение для управления списком задач. Позволяет создавать, редактировать и удалять задачи, искать их в поиске, отмечать их выполнение, получать вдохновляющие цитаты.

---

## Основные функции

- Просмотр списка задач с чекбоксами для отметки выполнения.
- Поиск задач.
- Редактирование существующих задач.
- Добавление новой задачи.
- Удаление задач с подтверждением.
- Отображение вдохновляющей цитаты с публичного API: [Zenquotes](https://zenquotes.io/).

## Навигация

- Главный экран — стартовый.
- Дополнительный экран — экран с вдохновляющей цитатой.
- Тап по задаче — открывает экран редактирования задачи.
- Кнопка "+" — открывает экран добавления задачи.
- При удалении задачи открывается диалог подтверждения.
- Кнопка "Отмена" или системная кнопка "Назад" возвращают на предыдущий экран.

---

## Сценарии использования

### Добавление новой задачи

1. Нажать кнопку "+" на главном экране.
2. Ввести название задачи (обязательно).
3. Ввести описание (опционально).
4. Нажать "Сохранить".
5. Задача появляется в списке на главном экране с текущей датой.

### Редактирование существующей задачи

1. Нажать на задачу в списке.
2. Внести изменения в названии или описании.
3. Нажать "Сохранить".
4. Задача обновляется в списке.

### Отметка задачи как выполненной

1. Нажать на чекбокс рядом с задачей.
2. Задача отмечается как выполненная (перечеркивание).
2. Состояние автоматически сохраняется.

### Поиск задач

1. Ввести текст в поисковую строку.
2. Список автоматически фильтруется в реальном времени.
3. Для отмены поиска - очистить поисковую строку.

### Удаление задачи

1. Нажать на иконку [🗑].
2. Подтвердить удаление в диалоге.
3. Задача удаляется из списка и базы данных.
